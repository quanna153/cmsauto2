# Markets feature

Task trang thị trường chỉ sửa trong folder này.

- `model.ts`: typed content cho page.
- `mock.ts`: mock song ngữ cho asset, signal, brief và watchlist.
- `adapter.ts`: boundary để sau này thay mock bằng feed thật.
- `index.tsx`: UI responsive cho `/vi-vn/markets` và `/en-us/markets`.
