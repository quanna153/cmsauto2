# Analysis feature

Task trang phân tích chỉ sửa trong folder này.

- `model.ts`: typed content cho thesis, report, indicator và risk.
- `mock.ts`: mock song ngữ dùng cho UI.
- `adapter.ts`: boundary để sau này thay mock bằng API.
- `index.tsx`: UI responsive cho `/vi-vn/analysis` và `/en-us/analysis`.
