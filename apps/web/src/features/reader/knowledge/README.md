# Knowledge feature

Task trang kiến thức chỉ sửa trong folder này.

- `model.ts`: typed content cho taxonomy, lessons, path và glossary.
- `mock.ts`: mock song ngữ dùng cho UI.
- `adapter.ts`: boundary để sau này thay mock bằng API.
- `index.tsx`: UI responsive cho `/vi-vn/knowledge` và `/en-us/knowledge`.
